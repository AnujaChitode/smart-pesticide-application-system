# 🌱  Smart Pesticide Application System

 Overview

The Smart Pesticide Application System is an intelligent agricultural solution designed to automate pesticide spraying in grape farms. The system uses image processing and machine learning to detect plant diseases and apply pesticides only where needed.

 Problem Statement

Manual monitoring of crops is time-consuming and inefficient. Excessive pesticide spraying increases chemical usage and harms both crops and human health.

 Objectives

* Detect plant diseases using image processing
* Automate pesticide spraying using a robotic system
* Reduce excessive chemical usage
* Minimize human exposure to pesticides

Technologies Used

* Raspberry Pi
* Arduino Uno
* Camera Module (Webcam)
* Machine Learning (Image Processing)
* Motor Driver & Relay Module
* Embedded C / Python

 System Working

1. A camera captures images of grape leaves.
2. Raspberry Pi processes images using an AI model.
3. If a disease is detected:

   * The robot moves to the affected area
   * Pump system sprays pesticide precisely
4. This ensures targeted spraying and reduces wastage.

 Hardware Components

* Raspberry Pi 4
* Arduino Uno
* Ultrasonic Sensor (HC-SR04)
* Motors & Wheels
* Relay Module
* Pump System
* Battery Pack

 Results

* Successful detection of plant diseases
* Targeted pesticide spraying achieved
* Reduction in chemical usage
* Improved efficiency in crop protection
